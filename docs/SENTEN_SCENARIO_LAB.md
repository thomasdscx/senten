# Senten Scenario Lab

Senten Scenario Lab is the controlled dogfood corpus used to prove architecture discovery, adoption analysis, and regression behavior against known applications.

Commands:

```bash
senten scenario list
senten scenario run missing-policy
senten scenario verify-all
senten scenario export --output apps/showcase/data
senten showcase build
```

The static showcase consumes **precomputed real Senten artifacts**. It does not execute arbitrary visitor repositories. This keeps the public demo safe while ensuring the output is generated by Senten rather than hard-coded marketing copy.
